# Market WatchDog

한국 단기금융시장(CP·ABCP·AB단기사채)의 발행·잔액·신용·만기 데이터를 월별로 수집·가공해,
머신러닝 기반 이상탐지 모델로 시장 스트레스를 정량화하고 실시간으로 시각화하는 Flask 기반 대시보드입니다.

담당자가 시장 상황을 직접 판단할 때 참고할 수 있는 **의사결정 보조 수단**으로 설계했습니다.

---

## 왜 이 구조인가

**월별 파이프라인 분리 이유**  
데이터 수집(크롤링) → 전처리 → DB 적재 → ML 모델 적용 → AI 요약을 단계별로 분리한 이유는, 각 단계가 실패했을 때 해당 단계만 재실행할 수 있어야 하기 때문입니다. 크롤링이 실패해도 전처리는 이전 데이터로 가능하고, `SKIP_CRAWL=1` 옵션으로 크롤링만 건너뛸 수 있습니다.

**SQLite를 쓴 이유**  
월별 갱신 주기의 단일 사용자 로컬 대시보드에서 PostgreSQL 같은 서버형 DB는 과한 선택입니다. SQLite는 파일 하나로 관리되고, 별도 서버 없이 배포할 수 있어 현재 단계에 적합합니다. 동시 접속이 필요해지면 PostgreSQL로 전환할 수 있는 구조(SQLAlchemy 없이 sqlite3 직접 사용)로 남겨뒀습니다.

**모델 결과를 JSON으로 캐싱하는 이유**  
ML 모델을 요청마다 실행하면 응답 지연이 생깁니다. 데이터가 월 1회 갱신되므로 파이프라인 실행 시 한 번만 모델을 돌리고 결과를 `model_output.json`에 저장한 뒤, Flask는 JSON을 읽어 서빙합니다. 실시간 추론이 불필요한 구조에서 API 응답 속도를 확보하기 위한 선택입니다.

**AI 요약을 파이프라인에 넣은 이유**  
페이지 로드마다 AI API를 호출하면 비용이 선형으로 증가합니다. 데이터가 월 1회 바뀌므로 요약도 월 1회만 생성하고 `ai_summary.json`에 캐싱합니다. 급하게 재생성이 필요할 때는 관리자 페이지 버튼으로 온디맨드 호출이 가능합니다.

**두 모델을 결합한 이유**  
Isolation Forest 단독으로는 "현재가 이상한가"는 알 수 있지만 "어느 방향으로 이상한가(자금 유입/유출)"를 알 수 없습니다. Sliding Window Z-score는 방향성과 추세를 보여주지만 다변량 패턴을 잡지 못합니다. 두 모델을 결합해 서로의 단점을 보완했습니다.

**Decoy 레이어를 표준 암호화 대신 쓴 이유**  
표준 암호화(AES-GCM)는 이미 DB·통신 레이어에서 처리해야 할 역할입니다. Decoy 레이어는 그 위에 추가되는 별개의 목적, 즉 "비인증 접근 시 접근 사실을 모르게 하면서 로그를 남기는 것"을 위해 설계했습니다. 강력한 암호화를 대체하는 게 아니라 탐지·지연·추적 용도입니다.

## 주요 기능

**INDICATORS** — 시계열 지표 대시보드  
CP·ABCP·AB단기사채 3개 시장의 잔액·발행액·만기구조·신용등급 비중을 2016년부터 월별 누적 차트로 제공합니다. 전체·24·12·6·3개월 기간 선택 및 커스텀 범위 조회를 지원합니다.

**시장감시** — ML 이상탐지 대시보드  
Sliding Window(Model 1) + Isolation Forest(Model 2) 두 모델을 결합해 시장 이상을 탐지합니다. CP·ABCP·AB단기사채 각각의 현재 레벨(정상/주의/경고/위험)을 카드로 표시하고, 시장 스트레스·추세 이탈 시계열 차트를 제공합니다. 담당자가 수치를 보고 직접 판단하는 구조이며, 시스템이 결론을 내리지 않습니다.

**AI 시장 해석 + AI 시장 도우미**  
현재 데이터를 바탕으로 비전문가 언어로 상황을 요약하거나 질의응답을 합니다. 시장에 익숙하지 않은 담당자가 수치를 해석하는 데 참고용으로 사용합니다.

**보안 레이어** — Date-Based Dynamic Decoy Security Layer  
에니그마 암호 컨셉을 적용한 자체 설계 레이어입니다. 비인증 API 접근 시 날짜·Seed 문서 기반으로 치환된 Decoy 데이터를 반환하고 접근 로그를 남깁니다. `/demo`에서 시연, `/admin`에서 Seed 관리 및 접근 로그를 확인합니다.

## 빠른 실행

Python 3.12 권장.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
# .env 파일을 열어 OPENAI_API_KEY 등 입력
python app.py
```

브라우저에서 `http://127.0.0.1:5000` 으로 접속합니다.

---

## 환경변수 설정 (.env)

`.env.example`을 복사해서 `.env`로 만들고 아래 항목을 채웁니다.

| 변수 | 설명 |
|---|---|
| `OPENAI_API_KEY` | OpenAI API 키 (AI 요약·채팅 기능에 필요) |
| `FLASK_SECRET` | Flask 세션 암호화 키 (임의 문자열로 변경 권장) |
| `ADMIN_ID` | 관리자 로그인 아이디 (기본: admin) |
| `ADMIN_PW` | 관리자 로그인 비밀번호 |
| `FLASK_HOST` | 기본 `127.0.0.1` |
| `FLASK_PORT` | 기본 `5000` |

## 관리자 콘솔

`http://127.0.0.1:5000/admin` — 관리자 로그인 후 사용합니다.

- **Seed 문서 선택**: `mail_archive/` 폴더의 업무 메일 12개 중 하나를 Decoy 암호화 Seed로 지정
- **접근 로그**: 정상 접근 / Decoy 반환 이력 확인
- **Seed 이력**: 버전별 변경 이력 조회

## 참고

- 크롤링은 Chrome + Selenium + `webdriver-manager`가 필요합니다.
- ML 모델 pkl 파일(`model/*.pkl`)은 저장소에 포함되지 않습니다. 최초 실행 시 `model/model2.py`로 학습이 필요합니다.
- `market_watchdog.db`는 저장소에 포함되지 않습니다. 전처리 CSV가 있으면 `db_upsert_patch.py`로 생성할 수 있습니다.
